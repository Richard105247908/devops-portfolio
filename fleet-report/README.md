# fleet-report

Reads a CSV of vehicles, validates each row, and prints the fleet data.

## Usage
python fleet_report.py

## What I learned
- Reading CSVs with `csv.DictReader`
- Converting types and handling bad rows without crashing

## Usage

```bash
python fleet_report.py
```
